Lista negra

Lo que no hace nunca, aunque se lo pidas

  • Pagar, generar cupones ni tocar el débito automático.
  • Darte de baja de una materia o desvincularte de un aula.
  • Cambiar tus datos personales o tu contraseña.
  • Buscar a otras personas en el buscador de UADE.
  • Cerrar tu sesión de WebCampus.

Esto está bloqueado en el cliente HTTP, por dirección. Un error en otra parte del código no alcanza para saltearlo.

Permisos

Un “dale, hacé lo que sea” no alcanza

  • Leer viene habilitado. Escribir (inscribirte, entregar, mandar un mail) viene apagado.
  • Cada permiso se prende desde la terminal tipeando su nombre, por ejemplo pia.inscribir. Antes te explica qué permite y qué no.
  • El agente prepara la acción y te muestra un resumen: qué, dónde y si se puede deshacer.
  • Confirmás en un diálogo de tu cliente. El agente no puede responderlo por vos, y sin ese diálogo no hay escritura.
Instalación · unos 5 minutos

Instalarlo en tu compu

Beta privada.

Por ahora se instala desde el código. Cuando esté publicado en npm alcanza con npx -y uade-mcp.

git clone https://github.com/malenitaa/uade-mcp.git ~/uade-mcp
cd ~/uade-mcp && npm install && npm run build
node dist/index.js login

El login abre una ventana del navegador. Entrás con tu cuenta de UADE y la ventana se cierra sola cuando aparece tu WebCampus.

claude mcp add --scope user uade -- node ~/uade-mcp/dist/index.js

Después abrí Claude Code y preguntá algo: “¿cuándo son mis finales?”.

Abrí Settings → Developer → Edit Config y sumá esto dentro de mcpServers, sin borrar lo que ya tengas:

"uade": {
  "command": "node",
  "args": ["/Users/TU_USUARIO/uade-mcp/dist/index.js"]
}

Cambiá TU_USUARIO por el tuyo y reiniciá Claude Desktop.

Abrí ~/.cursor/mcp.json y sumá esto dentro de mcpServers:

"uade": {
  "command": "node",
  "args": ["/Users/TU_USUARIO/uade-mcp/dist/index.js"]
}

Cualquier cliente MCP que acepte servidores por stdio. El comando es node y el argumento es la ruta a dist/index.js.

Por ahora no hay versión hosteada: el MCP necesita tu sesión, y esa sesión no sale de tu compu. Por eso todavía no funciona desde el celular.

Preguntas

Antes de instalarlo

¿Es oficial de UADE?

No. Es un proyecto de estudiantes, sin afiliación con la universidad. Usa las mismas páginas que ves vos cuando entrás a WebCampus.

¿Ustedes ven mis notas o mi contraseña?

No. No hay servidor nuestro: todo pasa entre tu compu y UADE. La contraseña la escribís en la página de Microsoft y el MCP nunca la ve.

¿Y la empresa del agente que uso?

Lo que el MCP le devuelve al agente (por ejemplo, tus notas cuando las pedís) pasa por ese agente como cualquier otra conversación. Si eso te preocupa, preguntá solo lo que quieras compartir.

¿Puede inscribirme o darme de baja solo?

Hoy no escribe nada. Cuando se sume la inscripción en PIA va a necesitar un permiso que prendés vos y tu confirmación en cada alta. Las bajas no se van a sumar.

¿Cada cuánto hay que iniciar sesión?

Cuando vence la sesión de WebCampus. El agente te avisa y corrés node dist/index.js login de nuevo.

¿Cómo borro todo?

Corré node dist/index.js logout para sacar las sesiones del llavero, borrá la carpeta ~/.uade-mcp y sacá el servidor de tu cliente.
